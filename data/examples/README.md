# Example upload files (for the "any company" demo)

These show TrendLens is **industry-agnostic**. The app's built-in "Use example data"
button loads the music/streaming sample — but to prove it works for *any* company,
upload the files here instead (a fictional **food-delivery** company, completely
different themes):

1. Home → **Customer feedback** → upload `delivery_feedback.csv`
2. Home → **Competitor data** → upload `delivery_competitors.csv`
3. (optional) **Campaign results** → upload `delivery_campaign_results.csv`
4. Enter a company name (e.g. "QuickBite") → **Analyse data**

Gemma will *discover* the themes from the data itself (delivery speed, pricing,
app reliability, support, food quality) — no config change needed. All rows are
fictional/synthetic.
